## Editing

Past entries use the existing CMS Events collection with `kind: past`, `occurredOn`, `photos`, optional `facts` and optional `source`. The journal excludes these records from upcoming events, annual calculations, invitations and calendar export. The public archive sorts records by the actual event date and provides year and value filters.
